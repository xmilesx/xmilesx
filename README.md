# Miles Gray

I've started businesses across construction, consumer products, chemical supply, hospitality, brand marketing, talent booking and event execution, and now I build AI agents that do the work of running them. My general contracting firm did residential, light commercial and commercial work in Washington, DC, one of the toughest places in the country to permit a building.

The AI tools I built for that firm ran on hundreds of bids and thousands of leads, covering pricing, lead scoring, schedules and job costing. I've also built an agent system that runs dozens of scheduled jobs a week for a business's research, production and scheduling, with a separate reviewer that checks the work before anyone sees it. Everything here is built for any business that runs on paperwork, deadlines and numbers.
